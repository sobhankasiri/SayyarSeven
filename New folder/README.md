# کافی‌نت سیار سون — نسخه فروشگاهی

## امکانات
- فروشگاه خدمات و سبد خرید
- ساخت کد سفارش
- انتخاب فایل دیجیتال، تحویل حضوری یا پست
- قیمت پایه و قیمت تخفیفی سون
- خبرخوان زمان‌بندی‌شده با GitHub Actions
- نقشه گوگل، نشان و بلد
- شماره تماس با نمایش صحیح چپ‌به‌راست

## پیام‌رسان‌ها
داخل فایل `data/config.json` لینک کامل ایتا، بله، سروش و تلگرام را وارد کنید.

مثال:
```json
"telegram": "https://t.me/USERNAME"
```

## نکته مهم سفارش
این نسخه روی GitHub Pages استاتیک است. سفارش در مرورگر ساخته و متن آن کپی می‌شود.
برای پرداخت بانکی واقعی، آپلود امن مدارک و پنل مدیریت سفارش‌ها باید بک‌اند و درگاه پرداخت اضافه شود.

## خبرخوان
فایل `.github/workflows/update-news.yml` روزانه اجرا می‌شود و از RSS منابع موجود در
`data/news-sources.json` خبرهای مرتبط را جمع می‌کند. بعضی منابع ممکن است RSS خود را تغییر دهند و نیاز به ویرایش داشته باشند.

## انتشار
همه فایل‌ها را در ریشه Repository با نام `kafenet-sayar-seven` جایگزین کنید.
GitHub Pages از branch `main` و مسیر `/(root)` فعال بماند.


# فعال‌سازی هوش مصنوعی اخبار

این نسخه هر ۶ ساعت GitHub Actions را اجرا می‌کند. بدون کلید API، خبر قبلی حفظ می‌شود و خبر حدسی منتشر نمی‌شود.

## افزودن کلید OpenAI

1. Repository را باز کنید.
2. Settings
3. Secrets and variables
4. Actions
5. New repository secret
6. Name را دقیقاً `OPENAI_API_KEY` بگذارید.
7. کلید API را در Secret وارد و ذخیره کنید.

## اجرای فوری

بعد از افزودن Secret:

1. به تب Actions بروید.
2. AI cafe news updater را انتخاب کنید.
3. Run workflow را بزنید.
4. Branch را main بگذارید.
5. Run workflow را تایید کنید.

اگر خبر مرتبط و قابل‌استناد پیدا شود، فایل `data/news.json` خودکار تغییر می‌کند و GitHub Pages دوباره منتشر می‌شود.

## کنترل کیفیت

- تاریخ، مبلغ، مدارک و شرایط بدون منبع حدس زده نمی‌شوند.
- خبر نامرتبط رد می‌شود.
- اگر اطلاعات ناقص باشد، در سایت نوشته می‌شود «در اطلاعیه رسمی بررسی شود».
- زیر هر خبر، شرایط، مدارک، مراحل، هشدارها و دکمه سفارش همان خدمت نمایش داده می‌شود.
